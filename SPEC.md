# User Stories

* **Guest:** As a Guest, I can list all `PUBLISHED` articles.
* **User:**
    * As a User, I can create a new article, which starts as a `DRAFT`.
    * As a User, I can update a `DRAFT` article I own.
    * As a User, I can `PUBLISH` a `DRAFT` article I own.
    * As a User, I can `ARCHIVE` a `PUBLISHED` article I own (soft delete).
* **Admin:** As an Admin, I can use a CLI command to `PUBLISH` or `ARCHIVE` any article on the platform.
